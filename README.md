# 🍽️ Microwave Oven Simulation System (Embedded C Project)

## 📌 Project Overview

The Microwave Oven Simulation System is an embedded application developed to simulate the basic working operations of a microwave oven using the PIC16F877A microcontroller.

The project was developed during the Embedded System Design internship at Emertxe Technologies using Embedded C and PICSimLab. It demonstrates real-time embedded system concepts such as timer operations, keypad interfacing, display handling, and control system implementation in a simulated environment.

---

## ⚙️ Features

• Timer-based microwave operation
• Keypad-based user input control
• Start and Stop functionality
• Display interfacing for operation monitoring
• Countdown timer implementation
• Operation completion indication
• Real-time embedded system simulation
• Event-driven system execution
• Microcontroller peripheral interfacing

## 🔄 Working Flow

1. System initializes the microcontroller and peripherals
2. User provides input using keypad
3. Timer value is configured
4. Microwave operation starts
5. Countdown timer runs in real time
6. Display continuously updates operation status
7. System stops after timer completion
8. Completion indication is displayed
